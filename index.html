Good to know

A few quick answers.

What is Grassed?

Grassed is presented here as an unofficial Minecraft launcher by Mobinhrr, designed to bring account management, version selection, mods, and instances into one app.

Which platforms are supported?

Windows downloads are available from the Grassed GitHub Releases page. A Linux build is coming soon.

Which login methods are supported?

The planned feature set includes Microsoft, Authlib, and offline/cracked account modes. Use only accounts and access methods you are authorized to use, and follow the applicable game terms.

Is Grassed an official Minecraft product?

No. Grassed is an independent, unofficial launcher concept and is not affiliated with, endorsed by, or sponsored by Mojang or Microsoft. Minecraft is a trademark of Microsoft Corporation.
